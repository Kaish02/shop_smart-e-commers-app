📲 App Features:
🔐 Login / Signup (REST API + Token-based Auth)
🏠 Home Screen with Products, Categories & Real-Time Search
📦 Product Detail Page (with Add to Cart / Wishlist)
🛒 Cart Functionality (Quantity update, Remove – using SQLite)
❤️ Wishlist stored locally with SQLite
💳 Checkout with Razorpay Payment Integration
✅ Order Confirmation Flow
👤 User Profile (View + Edit)
💡 Real-Time Functionalities:

🔍 Live Search from API (while typing)
🧠 Local storage with SQLite for both Cart & Wishlist
🔁 Pull-to-refresh across screens
🧾 API-driven product & user data

🛠️ Tech Stack Used:
Flutter – UI/UX Development
Provider – State Management
REST API – Backend Integration (GET, POST, PUT, DELETE)
SQLite – Cart + Wishlist (Offline Support)
SharedPreferences – Token storage only
Razorpay SDK – Secure Online Payments
DummyJSON API – Used for backend simulation
